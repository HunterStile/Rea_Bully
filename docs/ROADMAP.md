# Roadmap

The immediate goal is a local explorable reconstruction covering every recoverable world zone, with the character animations and ambient activities needed for exploration. Missions are outside this phase.

| Work | Current state | Evidence required before calling it complete |
|---|---|---|
| Windows setup | Local developer workflow works; clean-clone bootstrap incomplete | Successful reconstruction on a fresh machine from its own installed copy |
| World coverage | 85 zones catalogued; four levels in the verified milestone | Every recoverable zone built, accessible and checked for streaming, floor contact and traversal |
| Characters | Jimmy and seven NPCs in the verified scene; expanded cast in development | Correct individual skins, motion, placement and runtime behavior across areas |
| Ambient activities | Selected audio, patrols and doors; most props remain static | Contextual interactions and animation verified against source evidence and reference behavior |
| Physics | Original COL3 bodies integrated in selected areas; fallback remains | Collision coverage and traversal checks, including unsupported primitive cases |
| Presentation | Functional exploration prototype | Comparable footage, clear controls and measured stability on documented hardware |

Original population scheduling, full native AI, vehicles, combat, saves, minigames and the Lua native API bridge remain incomplete. The broader ambition includes more of Bully, but this page does not promise a complete campaign or a delivery date.

The strongest public demonstration would be a short, uncut route through several areas on Windows, showing NPC activities and working transitions, accompanied by exact setup instructions. That is a proposed milestone, not a video or clean setup already delivered.
